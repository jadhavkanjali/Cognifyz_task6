## Cognifyz Advanced Server-Side Functionality
## About the Project
A Node.js and Express.js application demonstrating advanced server-side functionality for a robust REST API.

## Features
- Middleware and request logging
- Background job processing
- Server-side caching
- API rate limiting
- Error handling and security headers

## Technologies
Node.js, Express.js, NodeCache, Helmet, dotenv.

## Run Locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.
